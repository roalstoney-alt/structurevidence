# Release checklist

- [ ] Operator identity and credential status confirmed.
- [ ] Hosting, processors, retention, backup, email, payment and AI facts confirmed.
- [ ] Counsel reviewed privacy, source-rights, correction, terms, refund and complaint scope.
- [ ] No draft placeholder or `NEEDS_*` assertion appears as a claimed public fact.
- [ ] Focused tests pass; baseline failures are explained rather than weakened.
- [ ] Synthetic migration test passes; historical production-data plan separately approved.
- [ ] Exactly three featured cases remain; NSCLC remains accessible but not featured.
- [ ] Scientific evidence cut-offs and `last_material_change` are unchanged.
- [ ] `.org` and `.com` release/rollback steps are separately approved.
- [ ] Explicit production authorization exists for deployment and any smoke submission.

`PRODUCTION_CONTENT_VERIFIED` may be set to `PASS` only after the actual deployed SHA, HTTP status and response body have been checked.
