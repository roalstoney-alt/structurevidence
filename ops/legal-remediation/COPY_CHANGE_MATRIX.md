# Copy change matrix

| Surface | Prior wording/behavior | Revised boundary |
|---|---|---|
| 800V featured card | “One named commercial deployment exists.” | One named operator reports one named deployment; source, 2026-09-20T10:46:47Z cut-off and unresolved independent validation/history/replication/adoption are in the same card. |
| Sodium featured card | Launch and 60 GWh agreement “supported”; named site unestablished | Attributes the counterparty-described cooperation agreement and states that the reviewed materials did not yield qualifying named commissioned-site evidence; expressly avoids global non-existence, chemistry, credibility and financing inferences. |
| Irkutsk featured card | Reported death and unknown-origin pneumonia; cause claims unestablished | Adds source attribution, exact existing cut-off, `REVIEW_INCOMPLETE`, and prohibits cause/responsibility inference from financial, procurement or logistics anomalies. |
| Commercial cycle | Superseded state corrected when a later cycle is purchased | Confirmed StructEvidence factual/citation/transcription/analysis error is corrected without another purchase; new sources, cut-off, universe or question may be separately scoped. |
| Intake acknowledgement | One confidentiality checkbox | Separate, unselected privacy-notice acknowledgement and confidentiality/authorization-boundary acknowledgement; no marketing/publication consent is collected. |
| Intake event | Optional customer narrative stored in `request_events.note` | Event note is minimal/null; optional narrative is isolated in `request_private_context` and available only through the Access-protected admin route. |
| `.org` privacy | Short list of order/payment data | Operator, purposes, required/optional impact, recipient categories, minimization, retention principle, request route and unverified-fact boundaries. |
| Publication history | General versioning language | Distinct CORRECTION, SCOPE_CLARIFICATION and EVIDENCE_ADDITION types plus CURRENT/SUPERSEDED/CORRECTED/RESTRICTED/WITHDRAWN states. |

Scientific evidence records, case cut-offs, evidence counts and `last_material_change` were not changed by these copy edits.
