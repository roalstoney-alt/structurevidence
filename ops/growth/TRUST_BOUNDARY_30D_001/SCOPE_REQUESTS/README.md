# Scope requests

Create a written scope only for a qualified `C`, `D`, or `E` conversation that supplies one falsifiable claim, a decision context and deadline, available evidence or source links, and a decision-critical unknown.

Each scope must define `CLAIM`, `AS_OF`, `KNOWN EVIDENCE`, `UNKNOWN GAP`, `SEARCH / VERIFICATION BOUNDARY`, `DELIVERABLE`, `STOP CONDITION`, and `PRICE BASIS`. Never promise a favorable result.
