# SE Temporal Evidence Challenge Pack — sample v0.1

STATUS = `INTERNAL_REVIEW_SAMPLE`

TASK_COUNT = `8`

KNOWLEDGE_CUTOFFS = `2026-09-20 through 2026-10-08`

SOURCE_SCOPE = `APPROVED_PUBLIC_STRUCTEVIDENCE_RECORDS_ONLY`

## Purpose

The pack tests whether a system can classify what attributable evidence
supports at a fixed historical cutoff without upgrading one bounded record into
a broader claim. The valid state vocabulary is:

`SUPPORTED`, `OBSERVED`, `UNKNOWN`, `NOT_ESTABLISHED`, `CONTRADICTED`.

The sample contains two supported claims and six claims that remain not
established. This is intentional: calibrated stopping is the target behavior.

## Files

- `tasks.jsonl` — answer-free task inputs and dated evidence bundles.
- `gold.jsonl` — expected structured outputs derived from frozen claim records.
- `source_manifest.json` — exact source paths and SHA-256 hashes.
- `SCORING.md` — deterministic scoring contract.
- `score.py` — standard-library scorer.
- `test_sample.py` — source, leakage, gold and negative-control tests.
- `RIGHTS_AND_RELEASE.md` — redistribution boundary.
- `example_submission.jsonl` — valid submission used for reproducibility tests.

## Required answer schema

One JSON object per task:

```json
{
  "task_id": "SE-TECP-001",
  "state": "SUPPORTED",
  "knowledge_cutoff": "2026-09-20T10:46:47Z",
  "evidence_ids": ["L1-EV-CML-PDRE-001-FIELD-DEPLOYMENT-001"],
  "boundary": "One operator record does not establish independent validation or replication.",
  "stop_decision": "STOP"
}
```

## Reproduce validation

From the repository root:

```bash
python3 -B ops/growth/SE_AI_DATA_001/SE_TEMPORAL_EVAL_SAMPLE/test_sample.py
python3 -B ops/growth/SE_AI_DATA_001/SE_TEMPORAL_EVAL_SAMPLE/score.py \
  ops/growth/SE_AI_DATA_001/SE_TEMPORAL_EVAL_SAMPLE/example_submission.jsonl
```

Gold answers are not generated by a model. Tests require every gold state and
cutoff to equal the corresponding frozen canonical claim JSON.
