## Differentiation result

The demonstrable difference is not generic expert annotation. It is a compact
task contract joining a dated claim, a knowledge cutoff, attributable evidence,
counterevidence or non-qualifying evidence, a controlled state, a stop rule and
deterministic scoring.

The strongest candidate distinction is evaluation of calibrated
non-generalization: a model loses credit when it converts one bounded record
into independent validation, replication, commissioning or causation.

This is a `PRODUCT_CAPABILITY_HYPOTHESIS`, not validated buyer differentiation.
UniPat's Echo already handles time alignment; PaperBenchX already uses
evidence-backed grading and clean replay; ExpertEval already encodes expert
judgment. Any external statement must preserve these overlaps.
