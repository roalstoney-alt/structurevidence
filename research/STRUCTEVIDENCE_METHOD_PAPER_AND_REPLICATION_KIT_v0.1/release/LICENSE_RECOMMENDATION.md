# License Recommendation (non-binding)

This file is a recommendation only. The project owner should make the final licensing decision before public release.

## Paper and prose

A common option for a methods preprint and public specification is **CC BY 4.0**, which allows redistribution and adaptation with attribution.

## Code

Keep code under the repository's existing software license if one already exists. Do not silently change the repository's software license as part of the paper release.

## Data / claim objects

Before applying a blanket open-data license, distinguish:

- StructureEvidence-authored metadata and state objects;
- externally authored source material;
- quoted material;
- customer-private or source-controlled evidence.

A license on StructureEvidence metadata does not grant rights to republish third-party source content.

## Recommendation

Use separate licensing notices for:

1. paper/specification prose;
2. software;
3. machine-readable metadata;
4. third-party source material.

Do not publish a license choice until the owner has explicitly approved it.
