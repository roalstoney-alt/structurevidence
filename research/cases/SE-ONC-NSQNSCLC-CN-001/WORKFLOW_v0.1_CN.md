# SE-ONC-NSQNSCLC-CN-001｜中国非鳞非小细胞肺癌证据链公开案例工作流 v0.1

日期：2026-09-28（知识截点）。公开状态：研究预览。部署目标：`structurevidence.org/cases/nsq-nsclc-china/`；商业域只负责合规研究申请，不在公共表单收集病历。

## 1. 问题与边界

研究问题：对于中国非鳞非小细胞肺癌（nsq-NSCLC），哪些证据分别支持分期相关的切除手术、局部放疗、特定适应证下的药物治疗，以及极特殊肺移植和 ECMO 生命支持的实际角色？对于已界定的 EGFR 突变、局部晚期或转移性、EGFR-TKI 治疗后进展人群，依沃西单抗联合培美曲塞与卡铂的试验结局是什么？医院真实用药剂量、调整、随访及结局的缺口能否通过合规采购汇总统计补足？

不同分期和适应证不得合并为同一个可选治疗清单。肺移植为极少数特殊病理和肺内局限情形的候选评估；ECMO 为心肺支持，不是抗肿瘤方案。首次公开版不处理患者病历，不推断个人成功率，不将跨试验或跨治疗方式指标排成优劣表。患者在临床团队评估可行方案后参与决定。

## 2. 公开证据首版

1. 中国国家卫健委原发性肺癌诊疗指南：限定手术和局部治疗的分期语境；引用时保留版本年份。<https://www.nhc.gov.cn/yzygj/c100068/202204/0c1f7d3aca0545abbeb02030ce255930.shtml>
2. 中国 11,958 人 IA–IIIA 期手术队列：仅能解释其入组的已手术 NSCLC 人群；进一步使用非鳞亚组数据前核对论文原表。<https://pubmed.ncbi.nlm.nih.gov/37062036/>
3. 国家药监局 2024 年依沃西单抗联合培美曲塞与卡铂批准适应证。<https://www.nmpa.gov.cn/zhuanti/cxylqx/cxypxx/20240524110617125.html>
4. HARMONi-A 随机试验 2026 年最终 OS 报告：322 人，55 个中国研究点，161/161；中位 OS 16.8/14.1 月，HR 0.74（95% CI 0.58–0.95），严重程度至少 3 级的治疗期间不良事件 67.1%/54.7%。这是试验人群结局，不是个人预后。<https://pubmed.ncbi.nlm.nih.gov/42307937/>
5. 2018 年中国 1,700 家三级医院 2,073 例 ECMO 研究：可验证使用次数和该数据集的院内结局；作者指出病种细度不足，不能推断肺癌 ECMO 结局。<https://link.springer.com/article/10.1186/s13054-020-03270-1>
6. ISHLT 移植候选人共识及 ELSO ECMO 指南：分别限定特殊评估和生命支持语境。<https://www.ishlt.org/education-and-publications/standards-guidelines-detail/consensus-document-for-the-selection-of-lung-transplant-candidates-an-update-from-ishlt>、<https://www.elso.org/ecmo-resources/elso-ecmo-guidelines.aspx>

本次为定向初筛，不宣称系统综述或完全覆盖最新中国肺癌治疗格局。对每条事实保存来源地址、标题、发布/事件/检索/知识时间、访问分类、支持的最窄断言、反证与未覆盖范围。当前仅为链接和元数据存证；源文件哈希未取得时标 `null`，不得伪称原文已快照存证。网站产物的 Git commit SHA 可单独记录。

### 合规数据询价最小规格（先询价，不预定采购）

- **人群**：病理非鳞 NSCLC；诊断/分期、EGFR 变异、既往 EGFR-TKI、既往系统治疗、治疗线次；纳入/排除及筛选人数。
- **暴露**：依沃西单抗及联合药物实际用量、相对治疗起始时间、疗程、减量/延迟/停药与原因；其他主要治疗或转换。
- **结局与反馈**：OS 的统一 time zero、死亡核实途径、最后随访和删失、时间点生存估计与在险人数；如有 PFS/影像缓解，应给评估频率及标准；不良事件、患者报告反馈如有需说明采集工具、缺失与响应偏倚。
- **交付**：医院/期间、数据口径、分母、缺失率、审计说明、聚合表及曲线/置信区间；小样本抑制、再识别评估、允许的公开引用范围和许可期限。默认不收患者级行，不要求真实日期或任何身份键。
- **统计风险**：单院选择偏倚、合并症与病情严重程度混杂、既往和后续治疗差异、时间相关偏倚、跨院死亡随访不全；观察性组间关联不能自动解释为因果治疗效应。

## 4. 公共答复规则

用户问“这个研究里多少人、什么终点、观察到什么结果”：按原研究/合法授权汇总数据回答，并展示适用人群、分母、观察期和不确定性。

用户问“我手术、药物、移植、ECMO 各有多少成功率”或“哪个最适合我”：停止计算和排序。答：“现有证据不足以计算您的个人成功概率。不同治疗适用人群和结局不同。我们可展示研究原有的队列结果及限制；请由了解完整病情的多学科临床团队评估哪些方案可行，并与您共同决策。”

用户提交病历：公共网站不保存病历，不在公开案例中引用。若未来另建患者授权流程，先明示目的、接收方、期限、访问控制及退出机制；与本公共研究页隔离。
