# Methodology Principles

PUBLIC CLAIM != REALITY

ARTIFACT INTEGRITY != CONTENT TRUTH

MULTIPLE URLs != INDEPENDENT SOURCES

HOSTING INDEPENDENCE != EVIDENCE INDEPENDENCE

CHANGE != CONTRADICTION

INCONSISTENCY != FALSEHOOD

OBSERVED CONTRADICTION != POTENTIAL FALSIFIER

APPARENT CONFLICT != MATERIAL INCONSISTENCY

## Proposed supplementary execution principle (pending human merge review)

**SE-META-VERIFICATION-001/v0.1 — The verifier must remain verifiable, including the method by which it verifies.**

- `VERIFIER_OUTPUT != METHOD_VALIDITY`
- `HIGHER_REVIEW_LAYER != INDEPENDENT_VALIDATION`
- `MULTI_AGENT_CONSENSUS != SOURCE_INDEPENDENCE`
- `METHOD_SELF_CONSISTENCY != EXTERNAL_VALIDITY`
- `PASS_WITHIN_SCOPE != UNIVERSAL_CORRECTNESS`
- `ADDITIONAL_VERIFICATION != DEMONSTRATED_NET_BENEFIT`

SE exposes bounded evidence states; RDL examines verification processes and method limits. Neither layer is self-certifying. Challenge methods upward, independently outward, and over time; retain falsifiers, costs, remaining unknowns, and authorized reopening triggers. These expressions are methodological guardrails—not newly proved scientific claims or extensions of existing evidence-state enums.

See [SE-META-VERIFICATION-001](../docs/engineering/SE_META_VERIFICATION_001.md). This proposal requires human approval before adoption; no automation, case state, release gate or historical record changes are authorized.
