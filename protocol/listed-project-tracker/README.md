# Listed-project tracker financial extension v0.1

Status: `DRAFT / HUMAN_GATE / NOT_PUBLICLY_ACTIVATED`.

This extension records financial-disclosure attributes alongside, and never in
place of, the Source Dependency model. The four axes are independent:

- source dependency;
- disclosure liability;
- assurance and its explicit scope; and
- disclosure stage.

`D4a` (cash collected) and `D4b` (customer-authored confirmation) are separate
dimensions. The stages are not a score, rating, confidence ladder, company
grade or inevitable progression. A contract does not establish recognized
revenue; recognized revenue does not establish cash collection; an issuer's
statement of customer acceptance does not establish a customer-authored
confirmation.

Every correction is a new append-only event that names the superseded record.
The draft does not define an investment action and does not change an existing
StructEvidence case state.
