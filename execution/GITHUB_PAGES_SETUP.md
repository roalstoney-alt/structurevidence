- Branch: `main`
- Folder: `/docs`
- Custom domain: `structurevidence.org`

Codex did not claim GitHub Pages is configured unless verified after push.

1. Open repository Settings.
2. Open Pages.

5. Save.
6. Add custom domain `structurevidence.org`.
7. Wait for DNS and certificate checks to complete.
