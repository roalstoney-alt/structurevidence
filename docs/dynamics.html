Timeline Model

Dynamics

R1.1 separates structural Level from structural Delta so a dated snapshot can describe condition without implying trend.

R1.1 Method Boundary

Structural Level describes what the dimension condition is at a dated observation. Structural Delta describes how it changed only when a valid comparable prior observation or explicit change event exists. A single structural snapshot can establish a Level, but usually cannot establish a Delta.
