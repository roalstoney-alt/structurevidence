## Open audit defects

The entry gate count is not accepted as closure evidence. CML01-CML34 are generated by batch PASS logic rather than independent validators. CML runtime records use compound freshness strings outside the canonical RDL vocabulary. The CML GDR adapter does not yet enforce event invalidation, material correction, missing counter-evidence, or product-context behavior. The data dictionary is a manually maintained subset, version history lacks the site-integration and audit-hardening revisions, and the `.org` homepage metadata names only the digital-asset domain.

## Sprint boundary

This closure changes audit behavior, freshness representation, GDR release enforcement, schema documentation, version history and site metadata only. It does not add pilots, categories, payments, upload paths, products, routing changes, Timeline semantics or scientific findings.
