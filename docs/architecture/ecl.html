ECL: Evidence Consistency Layer

Tests whether public claims and observations remain mutually reconcilable after time, scope, numerical, semantic and source-dependency normalization.

Role in system

Evidence Dynamics consistency layer. Positioned inside RDL -> RTP -> [Structural Dynamics -> MDL] + [Evidence Dynamics -> ECL] -> ECN.
