# CML Audit Version Policy v0.1a

The scientific protocol remains `CML_v0.1` and the Technical Risk module remains `STRUCTEVIDENCE_TECHNICAL_RISK_v0.1`. This sprint changes validation independence, freshness representation, release enforcement, schema documentation and public metadata; it does not alter the Identity-to-Decision scientific grammar or the four pilot findings.

The closure is therefore versioned as `CML_AUDIT_v0.1a`, alongside `CML_SITE_INTEGRATION_v0.1a`, rather than falsely renaming the protocol. The append-only version-history entry records both the implementation and audit closure chain.
