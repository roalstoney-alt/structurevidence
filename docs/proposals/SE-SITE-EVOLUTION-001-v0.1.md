# SE-SITE-EVOLUTION-001 Dual-Site Upgrade v0.1
Status: PROPOSED, NOT DEPLOYED. 2026-10-25.

Canonical brand: Verify Your Verify — Lower the cost of knowing what you can trust.

.org is public evidence protocol, case and gap registry, source dependence, citable temporal decision memory. .com is commercial scoped decision records, private watchlists, workflow integration and exports (mark proposed capabilities, never imply they are live).

## Preserve
- We can be wrong. We must remain auditable. All revisions append, with original evidence records and rubric versions immutable.
- No source found within reviewed scope does not prove no source exists globally.
- No invented savings, downgrade rates, qualifying sources or decision outcomes.
- Preserve IDs, existing routes, multilingual availability, indexing, pricing and intake unless separately approved.
- No auto-publish, auto-merge, direct state updates or confidential record exposure.

## Public-site changes
1. Method page metadata should describe cross-domain time-indexed evidence, not just old digital asset categories.
2. Provide a Source Dependency View: Who is actually saying this? Source, originator, dependence class, evidence level, scope, acceptance test, rationale and row challenge.
3. For each registered gap where data exists, display affected decision type, plain-language implication, closure test, evidence cutoff versus last check, review limitations, and versioned source rows.
4. Pilot an existing 800VDC gap with actual case evidence; CC illustrative seven-page statistics must not be published as original case observations.
5. Record human-reviewed challenges and corrected classifications as append-only events.

## Classification axes
Dependency classes: ISSUER_AUTHORED, DERIVED, PARTIALLY_DEPENDENT, INDEPENDENT, UNKNOWN. Hosting independent is not evidence independent. Deduplicate repeated statements by original evidentiary lineage. Lack of disclosed relationship is not evidence of a hidden conflict: preserve UNKNOWN when unverified.
Evidence levels: E0 intent; E1 design; E2 simulation/lab; E3 unattributed field claim; E4 attributable field record with site/period/method; E5 independent attributable field record. Gap qualification depends on that gap's explicit acceptance rules, not just source independence. E4 issuer-authored operator evidence can qualify for a gap that accepts it.

Store stable row IDs, originators, relationship evidence, original lineage, dependency class and reason, E-level and reason, gap qualification and reason, search scope, access, cutoff, review date, rubric version, reviewer decisions, hash and supersession links. Two reviewers only count as complete when actually performed. Reclassification appends rather than replaces. Counts explicitly bound to reviewed scope.

## Commercial-site changes
Homepage: Know what supports your decision—and what remains unproven.
Supporting line: Freeze a citable evidence state before your team commits. Track what changes, what remains unknown, and the conditions for revisiting the decision.
Journey: Define Decision > Evaluate Sources > Freeze Stop-Point > Export Decision Conditions > Track Changes.
Proposals: one-time decision record, private gap register, monitoring, and API integration. Existing prices stay until approved. CTAs link to the verified public example, existing approved claim-intake, and method. Report only measured telemetry, not hypothetical benefits.

Decision-condition export: decision ID, exact claim/scope, cutoff, last checked, gap IDs, acceptance rules, statuses, unknown and inaccessible sources, customer-defined trigger and fallback, protocol version, record hash. SE reports evidence; customer sets the action.

## Sequencing and acceptance
A: safe method metadata + rubric documentation.
B: source-lineage data model and immutable changes, regression tests.
C: public .org pilot and challenge UI, scope-qualified counts.
D: commercial .com explanatory copy, intake and tested cross-links.
E: measured private pilot and reporting.

Gates: zero protected raw history modification; no false quantitative claims; mirror and multilingual/hreflang/sitemap correctness; live URLs and API compatibility; privacy and source scopes; actual reviewer steps; explicit human deployment authorization.

Open decision: set evidence-based, reproducible boundary between partially dependent and independent sources before applying across cases.
